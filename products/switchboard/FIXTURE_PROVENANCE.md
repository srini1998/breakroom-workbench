# Fixture provenance

The orders, tenant names, role matrix and seeded policy/drop/starvation variants were authored for this local project. Order payloads are generated repeated ASCII characters; event UUIDs derive from the experiment namespace, seed and sequence. No customer, employee, private repository, production log or external training dataset is used.

Alice/Bob and Switchboard's four owner/viewer accounts are fictional test identities in the local Auth service. The existing Qwen model is used for inference only; no fine-tuning or other model training occurs. Its weights are not committed or redistributed. Supabase containers and npm dependencies retain their upstream licenses. The build does not assign a new distribution license to the user's repository.
